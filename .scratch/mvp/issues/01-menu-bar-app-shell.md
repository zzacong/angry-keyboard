# 01: Menu bar app shell

**What to build:** The app runs as a background menu bar app. Launching it shows a status item in the menu bar whose menu contains Quit. It has no Dock icon and opens no window.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] Launching the app shows a status item in the menu bar.
- [ ] Clicking the status item shows a menu containing Quit.
- [ ] Quit terminates the app.
- [ ] The app has no Dock icon and opens no window.
- [ ] The hello-world window and its placeholder content are gone.
