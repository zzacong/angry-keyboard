Every keystroke fires a shot.

Angry Keyboard is a macOS menu bar app that plays a sound on every key you press, in any app. No window, no Dock icon. It just makes typing loud.

Download for macOS macOS 14+, free, MIT licensed

Why it exists. My friends type on mechanical keyboards and the clacking drives me up the wall, so I built the opposite. It is a hobby project and it is genuinely fun.

Mail, your editor, a search box. Every key fires. Volume, mute and the overlap toggle are in the menu.

It only listens. Nothing you type is recorded, stored, or sent anywhere. Password fields stay silent, because macOS blocks the app while Secure Input is on.

Angry Keyboard is a small macOS app that plays a gunshot on every key you press, in whatever app you are in. I built it because my friends kept typing on mechanical keyboards and the clacking was driving me up the wall. It is a hobby project and I think it is funny.

The sounds

Six rules, one of them a catch-all for every key without its own sound.

  • Every other keyshotgun
  • Enterexplosion
  • Escaperocket whoosh
  • Backspaceshotgun blast
  • Spacebarshotgun cock
  • Arrow keysone of four impacts

How to get it

1Download it and open it. It sits in the menu bar and nowhere else.
2Turn on Input Monitoring when it asks. It opens the right System Settings pane for you.
3Type anywhere. It only listens, and password fields stay silent.
Download for macOS macOS 14 or later. Free and open source under MIT.
