What happens after you pick

  • App icon. The chosen SVG is rasterized to a single 1024×1024 PNG and dropped into AppIcon.appiconset. Xcode 27 takes the one file; no per-size images needed.
  • Menu bar glyph. Shipped as a template image in the asset catalog (or a PDF), not the current keyboard SF Symbol. The mute state points at the muted variant instead of speaker.slash.
  • About item. Add About Angry Keyboard to the status menu wired to orderFrontStandardAboutPanel; it then shows the new app icon with no extra work.
  • Fonts. Direction E uses a live glyph in this file; it gets outlined to a path before it ships.
